# Segbom Corretora de Seguros

Fundação inicial do novo site institucional multipáginas da Segbom.

## Tecnologias

- Next.js 15
- React 19
- TypeScript
- CSS responsivo sem dependências visuais externas

## Executar localmente

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.

## Validar produção

```bash
npm run build
npm start
```

## Estado atual

- Página inicial responsiva
- Página institucional
- Listagem de seguros
- Páginas dinâmicas para Auto, Residencial, Vida, Empresarial e Saúde
- Cotação visual
- Atendimento
- Conteúdos
- Contato
- Privacidade
- Página 404

## Dados pendentes

Antes da publicação definitiva, validar:

- Logotipo e arquivos da identidade visual
- Paleta e tipografias oficiais
- Telefone, WhatsApp, e-mail, endereço e horário
- CNPJ, razão social e informações regulatórias
- Seguradoras parceiras
- Canal de recebimento das cotações
- Política de privacidade definitiva
- Fotografias e depoimentos autorizados

O projeto não inventa dados empresariais, parceiros ou números de desempenho.
